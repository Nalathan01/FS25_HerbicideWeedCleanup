# Herbicide Weed Cleanup

Herbicide Weed Cleanup is a Farming Simulator 25 mod that clears the withered weed foliage left behind after spraying herbicide, so sprayed fields look clean again instead of staying covered in dead plants until the ground is worked.

## Features

- Automatically removes withered weeds after herbicide spraying
- Game setting to choose between two cleanup modes: Immediate (within a few seconds) or Delayed (once a month, lighter load for busy dedicated servers)
- Otherwise unchanged herbicide behavior (spot spraying, Precision Farming, environmental score, etc. are unaffected)
- Fully compatible with dedicated servers and multiplayer
