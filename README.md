# Herbicide Weed Cleanup

Spraying herbicide kills the weeds but leaves the dead foliage sitting on the field until the ground gets worked again, this mod clears that withered growth away so sprayed fields actually look sprayed.

## What it does

- Removes withered weed foliage automatically after herbicide spraying
- Choose between two cleanup timings in the game settings: Immediate (within a few seconds) or Delayed (once a month, easier on busy dedicated servers)
- Doesn't touch anything else about herbicide, spot spraying, Precision Farming and the environmental score all work exactly as before
- Works fine on dedicated servers and in multiplayer

## Feedback

Weeds not clearing the way you'd expect? Open a GitHub issue with your mod/game version, the map, which sprayer you used, and whether Precision Farming is installed. `log.txt` helps if it looks like a script error.
